Ce que cette maquette applique

  • 1 rôle = 1 couleur dominante, reste identique (mêmes icônes, même logo, mêmes gabarits) entre web et mobile.
  • Web : sidebar rétractable, navbar, contenu à onglets, panneau droit rétractable, popups, boutons-icônes dans les listes.
  • Mobile : 5 onglets bas, le 3ᵉ "+" déplie les actions secondaires, tout est cliquable/dépliable (disclosure imbriquée).
  • Chaque rôle web ou mobile, rarement les deux — seul le Client a les deux (règle d'or n°5).
  • Chaque écran a un état initial pensé (case "État initial") au lieu d'un vide silencieux — cf. scénario 0.
